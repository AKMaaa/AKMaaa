# デザインルール（Web サイト）

このファイルは **Astro で公開するポートフォリオ・研究実績サイト**（`src/pages/**` など）の見た目・UI・トーンの正とする。

参照の方向性: [露口啓二 / Fremen](https://www.fremen.biz/index.html) に象徴される、**余白と情報の削ぎ落としで成立する静かなギャラリー／アトリエサイト**。

ルートの `DESIGN_RULES.md`（ギャル・サイバーパンク、ターミナル、絵文字など）は **GitHub プロフィール README 専用**。サイトには一切持ち込まない。

---

## 0. スコープの切り分け

| 対象 | ドキュメント | トーン |
| --- | --- | --- |
| GitHub プロフィール (`README.md`) | ルート `DESIGN_RULES.md` | ギャル・サイバーパンク |
| Web サイト (`src/**`) | **このファイル** | 極限のミニマル／ギャラリー |

プロフィール用の色・グロー・ギャル語・絵文字・`akira@gal` プロンプトを、サイトの CSS・コピー・コンポーネントに流用しない。

---

## 1. デザイン哲学

### 1.1 一言で

**サイト自体を見せない。作品・実績だけが残るようにする。**

Web サイトは展示室の壁とキャプションに徹する。壁は白く、キャプションは小さく、ナビは声を潜める。色や装飾や「かっこよさ」はコンテンツ（写真・論文・発表タイトル）側からしか生まれない。

### 1.2 目指す印象

- 静か、落ち着いている、長い時間耐える
- 自信があるが自己主張しない（沈黙による権威）
- 印刷物のポートフォリオや美術館の壁面に近い
- 「AI が生成したポートフォリオ」に見えない

### 1.3 明示的に拒否するもの（Anti-AI / Anti-トレンド）

次は **禁止**。どれか一つでも入るとトーンが崩れる。

| 禁止 | 理由 |
| --- | --- |
| グラデーション背景（紫→インディゴ、ピンクネオンなど） | 「AI っぽい」定番パターンの代表 |
| グロー、ネオン、多層シャドウ | 装飾がコンテンツより先に目に入る |
| 大きな角丸カードの羅列、ダッシュボード風グリッド | 展示ではなく管理画面になる |
| pill ボタンの群れ、アイコン行、統計ストリップ | 情報のノイズ |
| ヒーロー上のフローティングバッジ／ステッカー | ギャラリー感を壊す |
| 絵文字、ギャル語、キラキラコピー | プロフィール用トーンの混入 |
| 派手なホバー（拡大バウンス、色反転フラッシュ） | 静けさの喪失 |
| 無意味なパララックス／ヒーロースライダー | トレンド依存・時間耐性の低さ |
| アクセントカラーの多用（ティール、オレンジ、ブランド紫など） | モノクロ＋コンテンツ色以外は持ち込まない |
| ハンバーガーメニュー | 装飾化しやすく、項目数が少ない本サイトでは不要 |

**判定テスト:** ナビと氏名を消したとき、残る画面が「白い余白に、静かな一文と実績」になっているか。装飾だけで成立しているなら失敗。

### 1.4 削減の原則（Elimination）

足す前に削る。迷ったら **入れない**。

1. この要素がなくても意味は伝わるか → 伝わるなら削除
2. 色がなくても階層は伝わるか → 伝わるなら色を足さない
3. 枠線がなくても塊は分かるか → 分かるなら枠を付けない
4. アニメがなくても視線の誘導ができるか → できるなら動かさない

## 2. 参照から取り込むこと／取り込まないこと

参照: [https://www.fremen.biz/index.html](https://www.fremen.biz/index.html)

### 2.1 取り込む（原則）

- **純白の地**と、余白が「素材」であること
- **非対称の二区画**（細い左レール＋広い右の主面）※PC
- **氏名がブランドの核**（和文は明朝、欧文は小さくサンセリフ）
- **ナビは小サイズ・lowercase・アイコンなし**
- **主コンテンツは白地に浮かぶ「額装」**（画面端までベタ塗りしない）
- **キャプションは小さく、端に静かに置く**
- **色はコンテンツからしか来ない**（UI は黒〜グレーのみ）
- **影・角丸・グラデ・ボタン見た目を捨てる**

### 2.2 このサイトでの翻訳

| Fremen 的要素 | 本サイトでの対応 |
| --- | --- |
| news | `/`（ニュース短報） |
| photographs / books | `/research`（発表・研究）、`/works`（アプリ作品） |
| bio | `/bio`（経歴＋スキル） |
| 左サイドの氏名 | `前田 祥` / `Maeda Akira` |

## 3. 情報設計（サイトマップ）

複数ページ構成。1 枚スクロールにまとめない。**ジャンルごとにページを分ける**（全部を1リストにしない）。

| パス | ナビ表記 | 中身 | データ源 |
| --- | --- | --- | --- |
| `/` | （氏名＝ホーム） | **画像 1 枚のみ**（額装。Fremen 型） | `public/images/` |
| `/news` | `news` | 短い告知の時系列 | microCMS `news` |
| `/research` | `research` | 学会発表・論文・受賞（研究成果） | microCMS `research` |
| `/works` | `works` | アプリケーション・Web 作品 | microCMS `works` |
| `/profile` | `profile` | 略歴・スキル・researchmap / GitHub / Facebook | Astro 静的データ |
| `/contact` | `contact` | メールアドレス・外部プロフィールリンク | Astro 静的データ |

- `/bio` は使わず `/profile` に統合（旧 URL はリダイレクト）
- 初期スコープ外: お問い合わせフォーム、統計、スキル％、カードグリッド
- 業績の正本は researchmap。サイトは入り口と抜粋

### 3.1 一覧 1 件の表示順（CMS 系共通）

1. 日付（小・`--muted`）
2. タイトル（明朝・本文色）
3. 補足（会場・媒体・技術名を平坦テキスト。pill にしない）
4. 本文（必要なときだけ）
5. テキストリンク

並びは日付降順。0 件時は「投稿がまだありません」。縦線＋光るドットは使わない。

---

## 4. トーン＆ボイス（コピー）

- 標準語。です・ます、または体言止めの短いキャプション
- 絵文字・感嘆符の多用は禁止
- 英字ナビは **すべて小文字**（`news`, `research`, `works`, `bio`）
- 見出しは短く。説明文は 1〜2 文まで
- 空状態: 「投稿がまだありません」

---

## 5. カラーシステム

UI は **モノクロのみ**。アクセントカラーは持たない。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#ffffff` | ページ背景（純白。ベージュ不可） |
| `--text` | `#111111` | 氏名・本文・主要リンク |
| `--text-secondary` | `#444444` | ナビ、やや弱い本文 |
| `--muted` | `#888888` | キャプション、日付、コピーライト、空状態 |
| `--line` | `#dddddd` | 本当に必要なときだけの区切り |
| `--focus` | `#111111` | フォーカスリング |

リンクは青の既定色にしない。本文同系の黒／濃灰＋下線で識別する。

## 6. タイポグラフィ（明朝を軸）

### 6.1 役割分担

| 役割 | フォント | 使い方 |
| --- | --- | --- |
| 和文氏名・ページ内タイトル・一覧タイトル・本文 | **Shippori Mincho**（400 / 500）＋システム明朝フォールバック | サイトの顔と読み物の核 |
| 欧文氏名・ナビ・日付・キャプション | **Cormorant Garamond**（300 / 400） | 細いおしゃれな欧文。italic は氏名のみ可 |

```css
--font-serif: "Shippori Mincho", "Hiragino Mincho ProN", "Yu Mincho", "Noto Serif JP", serif;
--font-en: "Cormorant Garamond", "Times New Roman", Times, serif;
```

**Brand test:** ナビを消しても、和文氏名（明朝）が「誰の場か」を示せていること。

### 6.2 サイズの階層（目安）

| 要素 | 目安 | 備考 |
| --- | --- | --- |
| 和文氏名 | `1.25rem`〜`1.75rem` | 余白で存在感を出す |
| 欧文氏名 | `0.9rem`〜`1rem`、weight 300、italic 可 | `Maeda Akira` |
| ナビ | `0.9rem`〜`1rem`、weight 300 | lowercase。項目間に息 |
| ページ見出し（Main 内） | ナビと同程度 | lowercase（`news` など） |
| 一覧タイトル | `1rem`〜`1.15rem` | weight 400〜500・明朝 |
| 日付・キャプション | `0.8rem`〜`0.9rem` | `--muted`・Cormorant |
| コピーライト | キャプション以下 | Side 最下部 |

### 6.3 行間・ケース・読み込み

- 本文行間: `1.8` 前後
- 英字ナビ: **lowercase 固定**
- Web フォントは **Shippori Mincho + Cormorant Garamond** の 2 ファミリーまで
- Google Fonts は `preconnect` ＋必要な weight のみ

## 7. レイアウト（PC / スマホで分ける）

ブレークポイント: **`768px`**（未満＝モバイル、以上＝デスクトップ）。

### 7.1 Desktop（`min-width: 768px`）

```text
| Side 14–16rem (sticky) | Main（残り・額装の余白）     |
| 前田 祥                 | ページ見出し（小・lowercase） |
| Maeda Akira             | 一覧 / 経歴・スキル           |
| news / research / …     |                               |
| copyright               |                               |
```

- Side 固定幅おおよそ `14rem`〜`16rem`。スクロール主体は Main
- Main は画面端に貼らない。上下左右に白場
- 本文の行長はおおよそ 40〜60 文字／行（`max-width` で抑制）

### 7.2 Mobile（`max-width: 767px`）

```text
前田 祥
Maeda Akira
news  research  works  bio   ← 横並び／折り返しテキスト（ハンバーガー禁止）
────────────────────────────────
Main（1 カラム。余白は少し詰めるが額装は維持）
```

- 氏名 → テキストナビ → コンテンツの順
- タップ領域は確保するが、見た目はテキストリンクのまま
- `/bio` 内の経歴とスキルは縦連続。セクション間は線ではなく余白
- 横スクロールを出さない

### 7.3 余白

- セクション間は「線」より「空白」
- **One job per section:** 1 セクション＝1 目的＋見出しは高くても 1 つ

## 9. ページ別の要素

### 9.1 `/`（home）

- ページ見出しなし
- 画像 1 枚＋任意の小さなキャプション（右寄せ可）
- 仮画像可。差し替えは `public/images/`

### 9.2 `/news`

- Main 見出し: `news`
- 短報リスト

### 9.3 `/research`

- Main 見出し: `research`
- 研究成果リスト

### 9.4 `/works`

- Main 見出し: `works`
- 作品リスト（縦。カードグリッド禁止）

### 9.5 `/profile`

- Main 見出し: `profile`
- 短い紹介文
- researchmap / github / facebook（URL があるものだけ。細い線アイコン＋ラベル）
- career / skills

### 9.6 `/contact`

- Main 見出し: `contact`
- メール（mailto）と facebook リンク
- シンプルなお問い合わせフォーム（name / email / message）。送信は FormSubmit（静的ホスト向け）
- researchmap / github は profile 側。contact には置かない
- 自前の重いフォーム UI・CAPTCHA の装飾は置かない

---

## 10. リンク・モーション・アクセシビリティ

- ホバー: 透明度のわずかな低下、または下線の濃化。色ジャンプ禁止
- 外部リンク: `target="_blank"` + `rel="noopener noreferrer"`
- モーションはほぼ静止。装飾アニメ禁止。`prefers-reduced-motion` を尊重
- `html lang="ja"`。フォーカスリングを消さない
- CSS 変数は `:root`（レイアウト）に集約。ページごとの色上書き禁止

## 12. やってよいこと／避けること（要約）

**よい:** 白場を増やす／文字サイズと余白だけで階層をつくる／迷ったら削る

**避ける:** AI っぽいグラデ・紫・グロー／プロフィール `DESIGN_RULES.md` の流用／装飾が実績より先に目に入ること
